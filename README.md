# Тестовое задание

## Требования

Разработать пользовательский интерфейс для отправки и получения сообщений в WhatsApp, используя сервис GREEN-API. Использовать технологию React.

## Запуск проекта

```
# Clone the repository
git clone git@github.com:ttpavlova/green-api-frontend-test.git

# Install dependencies
npm install

# Run in dev mode
npm run dev
```
